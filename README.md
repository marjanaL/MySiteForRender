# Простий персональний сайт на Render

Мій перший вебсайт, розгорнутий на Cloud PaaS платформі **Render.com**.

## 🚀 Про проєкт
Цей проєкт створено в рамках навчального завдання. Він містить базову HTML-сторінку, яка автоматично оновлюється в інтернеті при кожному оновленні коду в цьому репозиторії.

## 🛠️ Технологічний стек
* **HTML5** — структура та вміст сторінки.
* **GitHub** — контроль версій та збереження коду.
* **Render (Static Site)** — безкоштовний хостинг та автоматичний деплой.

## 📦 Як запустити локально
1. Склонуйте цей репозиторій або завантажте ZIP-архів.
2. Відкрийте файл `index.html` у будь-якому браузері (Chrome, Firefox, Edge).
